# Expense Tracker

## Overview
Expense Tracker is a simple web application that helps users manage their personal finances. Users can add their salary and expenses, track transactions, and view their remaining balance in real time.

## Features
- Add salary/income
- Add expenses
- View current balance
- Track all transactions
- Simple and user-friendly interface
- Automatic balance calculation

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
1. Enter your salary/income amount.
2. Add expenses with their respective amounts.
3. The application automatically updates and displays:
   - Total Income
   - Total Expenses
   - Remaining Balance
